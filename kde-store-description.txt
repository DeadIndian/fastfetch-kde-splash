Deads Fastfetch Splash Screen (Forked) v1.8

A matrix-style splash screen for KDE Plasma that uses 'fastfetch' to display your real system info — decoded character by character with a glitch animation, in full color.

Fork of herzane's fastfetch-kde-splash with ANSI color support and more.

FEATURES:
- True ANSI Colors: Your terminal's fastfetch colors (256-color and 24-bit truecolor) preserved exactly.
- 4 Layout Modes: Logo only, Logo + System Info (full), System Info only (info), Sequential (logo reveals, slides left, info fades in).
- Glitch Reveal Animation: Characters decode in random order.
- Animation Speed Control: Fast / normal / slow presets or fully custom timing.
- Theme Color & Background: Optional glow color, any background color or transparent.
- Multi-language Installer: English and Turkish, auto-detected.
- Robust Error Handling: Clear error message if fastfetch is missing.

CONFIGURATION (KDE Store Users):
The splash works out of the box in logo mode. For full customization (color, layout, background, speed), run the interactive installer from the GitHub repository, or edit directly:
  ~/.local/share/plasma/look-and-feel/fork-fastfetch-splash/contents/splash/Splash.qml
  - Set `property bool isConfigured: true`
  - Adjust `themeColor`, `glowEnabled`, `displayMode`, `bgColor`, and the animation speed properties.

GitHub Repository: https://github.com/DeadIndian/fastfetch-kde-splash

=== TÜRKÇE ===
Deads Fastfetch Splash Screen (Forked) v1.8

'fastfetch' aracını kullanarak gerçek sistem bilgilerinizi gösteren, tam renkli, karakter karakter çözülen glitch animasyonlu matris tarzı KDE Plasma açılış ekranı.

herzane'nin fastfetch-kde-splash projesinin ANSI renk desteği ve daha fazlasını içeren fork'u.

ÖZELLİKLER:
- Gerçek ANSI Renkleri: Terminalinizdeki fastfetch renkleri (256 renk ve 24-bit truecolor) birebir korunur.
- 4 Düzen Modu: Sadece logo, Logo + Sistem Bilgisi (full), Sadece Sistem Bilgisi (info), Sıralı (logo çözülür, sola kayar, bilgi belirir).
- Glitch Belirme Animasyonu: Karakterler rastgele sırada çözülür.
- Animasyon Hız Kontrolü: Hızlı / normal / yavaş ön ayarları veya tamamen özel zamanlama.
- Tema Rengi ve Arka Plan: İsteğe bağlı parıltı rengi, herhangi bir arka plan rengi veya şeffaf.
- Çok Dilli Kurulum: İngilizce ve Türkçe, otomatik algılanır.
- Sağlam Hata Yönetimi: fastfetch eksikse net hata mesajı.

YAPILANDIRMA (KDE Mağazası Kullanıcıları):
Açılış ekranı kutudan çıktığı gibi logo modunda çalışır. Tam özelleştirme (renk, düzen, arka plan, hız) için GitHub deposundaki etkileşimli kurulumu çalıştırın veya doğrudan düzenleyin:
  ~/.local/share/plasma/look-and-feel/fork-fastfetch-splash/contents/splash/Splash.qml
  - `property bool isConfigured` değerini `true` yapın.
  - `themeColor`, `glowEnabled`, `displayMode`, `bgColor` ve animasyon hız özelliklerini ayarlayın.

GitHub Deposu: https://github.com/DeadIndian/fastfetch-kde-splash
